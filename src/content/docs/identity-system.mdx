The identity system is everything the brand looks like before a word is
written: the wordmark, the palette, the type, the symbols. It is built from
four core elements, each with its own page.

This is the last definitive section of the wiki. Everything before it
describes what Balizen is; everything after it — the design guides, the
social pages — applies what's defined here. For the reel end frames that
combine these elements in a single frame, see
[Social Media: Formats](/social-media-formats/).

## The elements

- [Logo](/logo/) — the wordmark and its variations, and the artwork files
- [Color](/color/) — the core palette
- [Typography](/typography/) — the heading and body faces, with fallbacks
- [Symbols](/symbols/) — the symbol family and what each mark stands for
