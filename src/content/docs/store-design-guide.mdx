Color blocking in store follows the brand's [color](/color/), and the color stories set by the [Product Design Guide](/product-design-guide/).

- Should be reminiscent of a house, sectioned into: living room · bedroom · dining room/kitchen · kids area · gift/spa/accessories (cosmetic, drawstring bag, soaps, frames — gifting) · dressing room/closet
- Larger stores have clothing & accessories separate from homewares
- Color blocking: smaller stores keep warm/cool separate · medium store might combine two color stories on a shelf · larger stores clearly define all the color stories · colors typically follow rainbow gradient

## Posters

Posters hang throughout the store, and their format is semi-established: each
season the clothing posters are updated using a set format. It's open to
improvement — the aspiration is posters that say more about the process, the
artisans and the product, redone to be more refined: museum-y, exhibition
grade. This is what exists for now, and it's ok.

## Color blocking

Smaller stores keep warm and cool separate; larger stores define every color
story. In practice the shelf reads as a run of color rather than a jumble.
